# Documentação do Braseiro

Um Mestre de RPG que roda 100% offline num pendrive. Estes textos explicam como
ele funciona por dentro e por que foi feito assim. Para instalar e jogar, o
[README principal](../README.md) basta.

## Por onde começar

- **Quer entender o projeto em cinco minutos?** Comece pela
  [memória](memoria.md): é a ideia que sustenta o resto.
- **Vai mexer no código?** Leia a [arquitetura](arquitetura.md).
- **Vai colocar os livros do seu sistema?** O guia é [livros](livros.md).
- **Quer saber por que cada decisão foi tomada?** O
  [diário de bordo](diario-de-bordo.md) tem os números.
