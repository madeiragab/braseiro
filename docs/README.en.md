# Braseiro documentation

A tabletop RPG Game Master that runs 100% offline from a USB stick. These pages
explain how it works inside and why it was built this way. To install and play,
the [main README](../README.en.md) is enough.

## Where to start

- **Want the idea in five minutes?** Start with [memory](memoria.en.md): it is
  the idea everything else rests on.
- **Going to touch the code?** Read the [architecture](arquitetura.en.md).
- **Adding your system's rulebooks?** The guide is [rulebooks](livros.en.md).
- **Want to know why each decision was made?** The
  [build log](diario-de-bordo.en.md) has the numbers.
